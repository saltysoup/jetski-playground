# Kimi-K3 Distributed Serving on GKE (NVIDIA H100 GPUs)

This directory contains Kubernetes manifests and deployment scripts for serving **MoonshotAI Kimi-K3** (`moonshotai/Kimi-K3`) with **DSpark Speculative Decoding** (`RadixArk/Kimi-K3-DSpark`) across NVIDIA H100 80GB GPU node pools (`a3-highgpu-8g` / `a3-megagpu-8g` VMs) on Google Kubernetes Engine (GKE).
